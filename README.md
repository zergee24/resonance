# 共鸣 · AI 歌单

<img src="Support/AppIcon.png" width="96" alt="共鸣应用图标">

版本：0.3.0

共鸣是一个 macOS 本地工具：用耳机真实频响、你喜欢的声音参考和歌曲真实 PCM 频谱计算频段接近度，帮助你按歌看耳机，或按一副耳机找歌。结果是声学分析，不是音质评分，也不替代试听。

## 运行

需要 macOS 14.2+、Apple Silicon；系统播放器识别需要 macOS 15+。从源码构建还需要带 macOS SDK 的 Swift 6 工具链（Xcode 或 Command Line Tools）。

```sh
zsh scripts/build-app.sh
open dist/共鸣.app
```

构建产物是 `dist/共鸣.app`，应用只做本机临时签名，未使用付费开发者签名或公证。运行不需要 Python、ffmpeg、Codex、模型 Token 或 API Key。

## 第一次跑通

1. 打开“我的声学资料库”，点击“使用拉斐尔示例”。应用会载入 HBB 真实右声道曲线（480 点，19.5 Hz–20 kHz）和“平直参考（计算基线）”0 dB 曲线。
2. 应用预置 HE1 与 Alter Ego 无点档位两条真实偏好参考。在资料库勾选“我喜欢的声音”，两条分别计算，保留各自结果；可以随时关闭或换成自己导入的参考。平直参考保留为计算基线。
3. 用“导入音频…”选择一首本地歌曲，或播放网易云后打开“自动积累听歌资料”进行采集。
4. 在“根据歌曲找耳机”选择歌曲，查看你拥有的耳机更接近哪条偏好参考；也可以切到“根据耳机找歌曲”，按“偏好接近度”寻找值得试听的录音。

只有真实频谱、耳机曲线和参考的实际共同频段才会产生数值。缺资料时页面保留具体说明，不用歌名或标签补推荐。

## 两种模式与结果

“根据歌曲找耳机”比较标记为“我拥有”的耳机；“根据耳机找歌曲”固定一副耳机。默认“偏好接近度”使用听觉频带内的功率积分、压缩能量权重和整段统一电平对齐。数值越低，表示这段录音的频段表现越接近某条已选偏好参考；每条参考的整体、高频及局部偏差分别展示，不混成平均目标。只有一副耳机也可以使用。

逐帧计算保留按压缩帧能量加权的局部偏差 P90 和录音内差异最大的位置。它不是人耳响度或喜欢概率，没有使用未经校准的 SPL、等响曲线或语义标签。原有 C（谱形变化）、D（参考偏差）、Dhigh（10–20 kHz 偏差）可切换排序和查看。

D 越小表示在所选参考和共同频段内越接近。C 越大表示频谱改变更明显；两者都不等于好听。Dhigh 使用 10–20 kHz 的实际共同数据；高频能量很少或仅覆盖部分频段时仍给估计，并标明能量占比与范围。20 kHz 以上单独展示实际频段证据。

片段、小缺口、候选歌名或 EQ 状态未知时，应用可以按已采内容给出估计，并在结果旁说明限制。测量设备、补偿和播放处理作为备注保留，不因文字不一致直接抹掉可计算结果；曲线范围之外不外推。

## 采集与歌单

本地文件按完整文件导入，并保留原采样率和声道。播放器采集保留原格式和实际录音时长，没有固定 30 秒上限；自动识别可用时随暂停、切歌分段，手动采集需在切歌前点击“停止并分析”。关闭或退出时保存已有录音。无法证明完整覆盖时显示片段或完整度未知，不制造缺失时间。

“自动积累听歌资料”首次开启；手动关闭后会记住，下次启动保持关闭。它只跟随真实播放，不主动切歌或批量播放。优先读取系统 Now Playing 的完整歌名、艺人、专辑、进度和来源应用，播放器窗口隐藏或标题滚动不影响这条路径。当前自动采集仅支持网易云，并核对来源软件与采集进程。系统数据不可用时，回退辅助功能；也可显式启用窗口 OCR 识别。权限不足或采集失败时显示真实错误。

应用可以读取内置网页中已有网易云歌单的可见内容，保留歌曲 ID 和原始顺序，并把真实录音手动绑定到歌单原始行。点击“生成网易云歌单”，预览曲目、连接网易云网页账号并确认创建；应用通过正常网页操作写入，再核对目标歌单。缺少网易云歌曲 ID 的录音可先在资料库绑定链接。桌面客户端和内置网页的登录分别用于采集和建单。本地 JSON 导出仍保留。

0.2.6 复用 dsh 插件的 MediaRemoteMini 桥接，系统元数据不依赖辅助功能或屏幕录制权限。系统播放项 UUID 只区分播放段，不冒充网易云歌曲 ID；创建歌单前仍需绑定准确歌曲链接。实际验证与历史采集证据见 [TESTING.md](TESTING.md)，操作见 [使用说明](使用说明.md)。

创建结果暂时无法核对时，应用保留一次待核对记录，避免自动重复创建。可打开网易云查看、填写目标链接重新核对，或在人工检查后开始新的创建。当前播放有精确歌曲 ID 且本地已有分析时，先展示已有结果，同时继续积累本次录音。

scripts/verify-core.sh

scripts/verify-listening.sh

## 数据与来源

系统桥接使用随包附带的 MediaRemoteMini（BSD-3-Clause），依赖 macOS 私有 MediaRemote 服务；随系统升级可能发生变化，失败时显示原因并保留识别备选。来源与许可证见 [Support/SystemPlayer](Support/SystemPlayer)。

资料保存在 `~/Library/Application Support/Resonance`，包括本地元数据、原始音频和频谱文件；关闭应用不会上传音频。

拉斐尔 sample 文件：[Artipical_Raphael_HBB_R.csv](Samples/Raphael/Artipical_Raphael_HBB_R.csv)。

sample 来自 HBB 公开数据：[原始 AudioTools 文件](https://hbb.squig.link/data/Artipical%20Raphael%20R.txt) · [HBB 数据库](https://hbb.squig.link/)。它只有右声道，测量设备与补偿信息以来源备注为准，不代表本项目自行测量；20 kHz 以上没有该 sample 的曲线。

内置偏好曲线与可核验来源见 [HE1 / Alter Ego 数据](Samples/PersonalReferences/README.md)。声学研究与实现取舍见 [听觉与偏好研究](docs/research/headphone-preference.md)、[超高频研究](docs/research/extended-high-frequency.md)。两款耳机各 957 点，最高约 19.897 kHz；测量夹具未逐产品确认，跨来源对比仍是估计。

更多操作见 [使用说明](使用说明.md)，完整行为边界见 [产品规格](spec.md)。
