# 共鸣 · AI 歌单

macOS 原生首版。使用耳机数值频响与真实 PCM 频谱，在本机计算匹配；名称、歌手和风格标签不进入评分。

当前为 0.1.1 实验性首版，录音稳定性尚未验收：本机 Core Audio 仍出现启动超时，应用已改为后台启动并在 10 秒内报告错误，避免界面卡死。本地音频文件导入不依赖该采集路径。详见 [验证记录](TESTING.md)。

## 运行

需要 macOS 14.2 或更新系统、Apple Silicon，以及带 macOS SDK 的 Swift 6 工具链（Xcode 或 Command Line Tools）。从源码构建：

```sh
git clone https://github.com/zergee24/resonance.git
cd resonance
zsh scripts/build-app.sh
open dist/共鸣.app
```

构建产物位于 `dist/共鸣.app`，不随源码提交。应用仅本机临时签名，未使用付费开发者签名或公证。运行时不消耗大模型 Token，不需要 Python、ffmpeg、Codex 或 API 密钥。

文档：[使用说明](使用说明.md) · [产品规格](spec.md) · [验证记录与未验收项](TESTING.md)。产品规格包含后续范围，具体已实现能力以本页及验证记录为准。

仓库附带 [拉斐尔真实曲线 sample](Samples/Raphael/Artipical_Raphael_HBB_R.csv)（HBB，右声道，480 点，19.5 Hz–20 kHz）。在“我的声学资料库”导入该 CSV 即可查看曲线；来源、测量限制和导入方式见 [sample 说明](Samples/Raphael/README.md)。

## 使用路径

1. 在“我的声学资料库”导入耳机 CSV/TXT，或在“查询耳机曲线”打开毁 HiFi 测评详情后读取曲线。只接受已确认的频率响应数值；相位、失真和阻抗不作为频响导入。填写实际测量体系、有效范围，明确勾选“我拥有”。
2. 导入同测量体系、同补偿基准的参考目标，并为耳机关联参考。测量体系未知、参考缺失、20 Hz–20 kHz 覆盖不足时不排名。填写同一个体系名称需要实际依据，不能通过改名称让不兼容测量变得可比。
3. 导入本地音频，或开启“自动积累听歌资料”并播放网易云。该开关首次默认开启；手动关闭后会持久化，下一次启动保持关闭，不会被强行打开。它与“跟随当前播放”独立：仅在监听识别到播放状态为 `playing`，且读到歌曲 ID 或候选标题时记录本地歌曲信息并尝试采集，不凭空补 ID。首次系统音频录制权限由用户处理；权限不足时只提示状态并记录能读到的元数据。采集网易云进程输出，不使用麦克风；没有固定 30 秒上限，持续到用户停止、暂停、关闭或退出，停止后分析整段有效音频。“停止并分析”只结束当前段，下一次切歌或暂停后再播才恢复；失败可手动重试当前歌曲，不会无限自动重试。录音前的播放处理声明应与实际设置一致。
4. “根据歌曲找耳机”比较已拥有的耳机；“根据耳机找歌曲”按特色变化、综合偏差或 10–20 kHz 偏差排序。特色变化 C 不等于音质；D 越低代表越接近当前参考。
5. 派生子歌单：在应用内打开网易云歌单详情并“读取歌单”。在资料库将真实录音“用于歌单曲目”，明确确认录音与目标歌曲版本对应。片段需要打开“允许片段结果”。选择适配结果后可导出本地 JSON，或进入“写入网易云”预览，检查曲目 ID 和顺序再创建新歌单。

网页和原生网易云的登录状态彼此独立。新建歌单通过普通网页操作；需要在应用内登录。原歌单保持不变。写后数量、ID 与顺序未完全回读一致时，不显示成功；遇到不确定写入不会自动重试创建。

## 频段与计算

展示为 30 个约 1/3 倍频程区间（20 Hz–20 kHz），以及 20–25、25–31.5、31.5–40、40–50 kHz 等扩展区间。展示区间不替代 FFT 频率网格；部分频段显示实际覆盖。

原始采样率、左右声道、逐帧 Hann PSD 均保留。计算主区间固定为 20 Hz–20 kHz，使用频率单元重叠宽度积分，不外推曲线。C 表示谱形变化，D 为歌曲能量加权的参考偏差，D_high 为 10–20 kHz 的偏差。20 kHz 以上显示物理证据，不默认增加“音质分”。不同参考/测量体系独立分组。

## 当前边界

- 这是可运行的首版，不代表 spec.md 全部条目已完成。批量自动播放/采集队列尚未实现；自动积累不会主动切歌、批量播放或自动写网易云歌单。仍可逐首采集或批量导入本地音频，再显式绑定歌单原始行。
- 原生当前歌曲使用辅助功能，窗口 OCR 为可选备选；需要系统权限。OCR 只提供候选身份，不能生成精确歌曲 ID，精确链接可手动绑定。
- “自动积累听歌资料”与“跟随当前播放”是独立控制项，界面持续显示记录状态并可随时关闭。跟随切歌会清除上一首的排名；不同播放段分别留存，不自动跨母带或播放处理合并。切歌、跳播或身份丢失时，应用按最后一次同曲身份观察时间保守排除尾部并保留原 PCM 与分析产物；界面轮询不能证明交叉淡入的精确边界，该段不参与自动排名。缺少开头、结尾或存在跳过区间不能称完整。暂停或手动停止只有在歌曲身份相同、无丢帧且播放处理已声明等证据齐全时，才按实际覆盖评估。
- 网易云网页仅返回可见内容；当前公开歌单测试仅显示 10/111 首，应用保留不完整状态。没有绕过网页可见性限制。
- 附带的拉斐尔 sample 来自 HBB 真实右声道测量，但测量体系及兼容参考尚未确认，因此没有给出实际适配排名；未补造左声道或 20 kHz 以上数据。毁 HiFi 在本次验证时搜索无该型号结果。
- 尚未完成真实账号的新歌单创建与写后回读验收，导出适配器保留明确失败/不确定状态。
- 数值模型表达“参考偏差/谱形变化”，不代替主观听音验证。左右测量可分别作为配置导入；首版未提供双侧曲线合并、PEQ 编辑和多人校准。
- 逐帧谱数据量较大，当前适合有限歌单本地验证；没有自动预扫整个音乐库。

数据目录：`~/Library/Application Support/Resonance`，包含 SQLite 元数据、Audio 原始录音、Features 压缩谱数据以及网页写入日志。关闭应用后可以备份整个目录。采集失败的原始片段保留在本机，不进入有效排名。

## 验证

```sh
scripts/verify-core.sh
zsh scripts/verify-capture.sh
```

该原生断言程序不依赖 XCTest，可验证附带的拉斐尔曲线导入、AudioTools 元数据过滤、PSD、C/D/D_high、边界积分与高频部分覆盖。XCTest 源码仍在 `Tests`；本机 Command Line Tools 缺少 XCTest，`swift test` 尚不能执行。

除已注明来源的拉斐尔数值 sample 外，仓库不包含录音、账号登录数据、其他实测曲线、构建产物或本机测试日志。验证脚本生成的报告保存于已忽略的 `test-output/verification/`。
